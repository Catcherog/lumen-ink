# 02｜产品策略与版本边界

## 1. 产品定义

**光砚 Pro** 是面向小型摄影工作室的人像 AI 修图工作台，将自然人像精修、色彩匹配、局部清理、版本审阅和交付整合为一条可恢复、可比较、可复用的流程。

### 不做什么

- 不做通用文生图平台；
- 不做 Photoshop 全功能替代；
- 不把 Provider 管理作为主体验；
- 不在 P0 支持复杂图层、PSD 或多人实时协同；
- 不用未经验证的业务提升数据作为产品成功证明。

## 2. 目标用户

### 主用户：摄影工作室修图负责人

- 需要稳定产出自然、保留身份的人像；
- 同一组照片需要一致风格；
- 需要快速试错、版本回退和客户确认；
- 不愿管理多家模型的提示词差异。

### 次用户：摄影师/选片人员

- 需要对单张样片进行快速预览；
- 需要标记采用、提出修改和导出预览。

### 后续用户：客户

- 只使用 Preview 模式；
- 不接触 API、模型、复杂参数；
- 只获得低分辨率或水印预览。

## 3. 核心任务

1. 上传一张人像，并在 30 秒内理解下一步。
2. 用安全预设产生第一版自然结果。
3. 对局部问题进行补充修改，而不是从头重做。
4. 在原图与多个版本间可靠比较。
5. 确认一个版本并导出。
6. 失败、刷新或切换页面后能够恢复。

## 4. 产品原则

1. **任务优先**：先选择要解决的问题，再由系统选择模型。
2. **保护优先**：身份、构图和皮肤纹理保护默认开启。
3. **版本优先**：每次生成产生新版本，不直接覆盖。
4. **状态透明**：不显示虚假进度，显示真实阶段与错误。
5. **渐进复杂度**：常用设置在主面板，高级 Prompt 和模型设置折叠。
6. **可解释成本**：生成前显示预计耗时、分辨率和成本等级。
7. **可恢复**：所有关键操作有重试、恢复或回退路径。

## 5. 北极星指标与目标值

> 以下为 V2 验收目标，不是当前已实现数据。

### 北极星

**首轮可交付率**：标准人像使用默认预设生成后，经人工判断可直接采用或只需一次局部修改的比例。

### 产品指标

| 指标 | P0 目标 |
|---|---:|
| 首次用户从上传到发起生成 | ≤ 60 秒 |
| 标准人像首轮可交付率 | ≥ 70% |
| 任务成功率（排除供应商额度/封禁） | ≥ 95% |
| 刷新后项目恢复率 | 100% |
| 2K 结果生成 P95 | ≤ 90 秒 |
| 身份保留人工评分 | ≥ 4/5 |
| 自然度人工评分 | ≥ 4/5 |
| P0 阻断级错误 | 0 |

## 6. 版本范围

### P0：可靠单图工作台

- 项目/照片/版本结构；
- 人物、色彩、清理、局部、导出五个任务域；
- 智能路由与高级模型抽屉；
- 预设 + 5 档参数 + 补充要求；
- 生成任务状态、取消、重试和恢复；
- 版本条、对比、恢复、采用；
- 本地或服务端持久化；
- 安全、错误和埋点基础。

### P1：专业效率

- 画笔/蒙版和多人脸选择；
- 多候选结果；
- 批量导入、预设同步和任务队列；
- 参考图角色化；
- 分享审阅与评论；
- AI 图像诊断和修图建议；
- Preview 客户模式。

### P2：规模化与智能质量

- 团队权限和审计；
- 批次风格一致性；
- 自动质量检查；
- 模型基准库与动态路由；
- 色彩空间、印刷和完整交付管理。
