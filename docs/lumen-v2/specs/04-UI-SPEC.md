# 04｜UI 与交互规格

## 1. 桌面端布局

目标分辨率：1440×900 及以上；最小可用宽度 1180。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ Logo  项目名  保存状态             撤销 重做  对比          导出  设置 账户 │ 56
├───────┬───────────────────────────────────────────────┬─────────────────────┤
│ 项目  │ 画布工具：适应 100% 平移 对比 蒙版            │ 当前任务：人物精修  │
│ 人物  │                                               │ 预设                 │
│ 色彩  │                  画 布                        │ 身份/自然度保护      │
│ 清理  │                                               │ 参数组               │
│ 局部  │                                               │ 补充要求             │
│ 导出  │                                               │ 预计耗时/成本        │
│       │                                               │ [生成预览]           │
├───────┴───────────────────────────────────────────────┴─────────────────────┤
│ 原图 | V1 成功 | V2 失败 | V3 采用 | + 版本详情                         │ 96
└─────────────────────────────────────────────────────────────────────────────┘
```

### 尺寸

- 顶栏：56px。
- 左侧任务栏：72px 收起 / 184px 展开。
- 右侧参数面板：360px，最小 320px，最大 420px。
- 底部版本条：96px。
- 画布背景：深灰中性，不使用纯黑。

## 2. 顶栏

### 左侧

- 产品标识；
- 可编辑项目名；
- 保存状态：已保存、保存中、离线、保存失败。

### 中/右侧

- 撤销、重做；
- 对比模式；
- 导出主入口；
- 设置；
- 账户。

Provider/模型不得出现在顶栏。高级模型设置放入“设置 > 模型策略”。

## 3. 左侧任务栏

使用图标 + 中文标签，顺序固定：

1. 项目
2. 人物
3. 色彩
4. 清理
5. 局部
6. 导出

鼠标悬停显示一句能力说明。任务栏只负责切换任务域，不直接触发生成。

## 4. 画布

### 默认状态

- 图像居中；
- 支持适应窗口、100%、缩放、平移；
- 画布上方显示当前版本、尺寸、缩放比例；
- 拖拽上传仅在 EMPTY 状态启用。

### 对比模式

- 关闭；
- 左右拖动；
- 并排；
- 闪烁切换。

缩放和平移必须同步。对比对象默认是“当前版本 vs 父版本”，允许改为任意版本。

### 生成状态

保留当前图片，不用白屏或整页 Skeleton。画布上覆盖轻量任务卡：

- 当前阶段；
- 已等待时间；
- 可取消；
- 可在后台继续。

禁止显示没有真实依据的 0—100% 进度。

## 5. 右侧参数面板

### 顺序

1. 任务标题和一句说明；
2. 预设卡；
3. 保护项；
4. 参数组；
5. 参考图（折叠）；
6. 补充要求；
7. 高级 Prompt 预览（折叠）；
8. 预计耗时、输出尺寸、成本等级；
9. 底部固定“生成预览”。

### 人物参数

每项使用 5 档控制，不使用精确百分比：

- 关闭；
- 轻微；
- 自然；
- 明显；
- 强烈。

默认预设“自然精修”：

- 肤色：轻微；
- 皮肤质感：自然；
- 瑕疵：自然；
- 脸型：关闭；
- 五官：关闭；
- 光影塑造：轻微。

### 保护项

默认开启：

- 身份锁定；
- 构图锁定；
- 皮肤纹理保留；
- 服装和背景保留。

“强烈”参数与保护项冲突时，界面必须给出警告。

### 主操作

CTA 文案始终为“生成预览”。

禁用条件：

- 无输入图；
- 无可用模型；
- 当前存在未提交的必填错误；
- 正在提交同一配方。

## 6. 版本条

每个版本卡片显示：

- 缩略图；
- `原图 / V1 / V2`；
- 成功、生成中、失败；
- 创建时间；
- 采用/置顶状态。

点击切换查看；双击进入对比；右键或更多菜单支持：恢复、复制配方、标记采用、删除。

## 7. 空状态

中心卡片：

- 标题：上传一张人像开始；
- 主按钮：上传照片；
- 次按钮：使用示例；
- 文件限制；
- 隐私说明；
- 最近项目列表。

上传前隐藏右侧复杂参数，仅显示流程说明。

## 8. 视觉系统

### 风格

- 专业工具感，不做营销页式大渐变。
- 中性背景承托照片，品牌蓝只用于选中、主操作和状态。
- 颜色不承担唯一状态表达，配合图标和文字。

### 建议 Token

```css
--bg-app: #F4F6F8;
--bg-panel: #FFFFFF;
--bg-canvas: #20242B;
--border: #E3E7ED;
--text-primary: #161A22;
--text-secondary: #626B7A;
--brand: #5368E8;
--brand-hover: #4558D4;
--success: #1F9D68;
--warning: #C98318;
--danger: #D64545;
--radius-sm: 8px;
--radius-md: 12px;
--shadow-panel: 0 8px 24px rgba(22,26,34,.08);
```

### 字体与可用性

- 正文最小 13px；控制标签 13—14px；
- 点击区域最小 36×36；
- 键盘可达；
- 明确 focus ring；
- 关键对比度满足 WCAG AA。

## 9. 响应式

- 1180—1439：左栏收起，右栏 320px。
- 900—1179：右栏改抽屉，版本条保留。
- <900：P0 不承诺完整编辑，仅显示“建议桌面端使用”；允许项目查看和导出。
