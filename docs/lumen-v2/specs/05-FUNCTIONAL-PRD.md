# 05｜功能 PRD 与优先级

## P0 Epic 1：项目工作区

### P0-001 新建与恢复项目

**需求**：上传图片时自动创建项目，项目至少包含名称、原图、当前版本、更新时间和未完成任务。

**验收**：

- 上传后 2 次交互内进入可编辑状态；
- 刷新后恢复项目、原图和当前版本；
- 无数据时显示明确空状态；
- 保存失败时有可见状态和重试。

### P0-002 项目顶部状态

显示项目名和保存状态，不显示 Provider。

## P0 Epic 2：任务型编辑

### P0-101 任务导航

人物、色彩、清理、局部、导出使用稳定文字标签。

### P0-102 配方模型

一次生成配方包含：任务、预设、参数、保护项、参考图、补充要求、输出策略和 Prompt 编译器版本。

### P0-103 单一主操作

页面只有一个“生成预览”主操作。删除或降级其他触发模型调用的按钮。

### P0-104 参数档位

人像参数使用 5 档；系统保存语义值而不是 UI 像素位置。

## P0 Epic 3：智能模型路由

### P0-201 默认自动路由

用户选择质量/均衡/速度，不选择 Provider。

### P0-202 高级模型抽屉

高级用户可查看候选模型、能力、预估耗时和当前可用性。锁定模型后如果能力不匹配，禁止提交并给出原因。

### P0-203 失败转移

供应商额度、超时或暂时不可用时，允许自动切换或由用户确认切换。

## P0 Epic 4：生成任务

### P0-301 创建任务

提交后立即创建任务 ID，避免浏览器一直等待单一 HTTP 响应。

### P0-302 阶段状态

至少包括：queued、uploading、analyzing、generating、postprocessing、saving、succeeded、failed、cancelled。

### P0-303 重试与取消

失败任务可保留原配方重试；运行中允许取消。取消后不生成成功版本。

### P0-304 刷新恢复

刷新后继续显示未完成任务状态。

## P0 Epic 5：版本与对比

### P0-401 不可变版本

每次成功生成创建新版本，原版本不覆盖。

### P0-402 版本条

显示缩略图、编号、状态和采用标记。

### P0-403 对比模式

左右拖动、并排、闪烁；缩放和平移同步。

### P0-404 恢复与采用

支持恢复到任一成功版本、复制配方和标记采用。

## P0 Epic 6：质量保护

### P0-501 保护项

身份、构图、皮肤纹理、服装背景默认开启。

### P0-502 输出检查

成功结果至少检查：文件可解码、尺寸合理、非空、无明显服务错误图。

### P0-503 人工质量标签

每个版本可标记：身份漂移、过度磨皮、构图漂移、局部失败、可采用。用于后续路由评估。

## P0 Epic 7：安全与可靠性

### P0-601 生产密钥 fail-fast

生产环境缺失 JWT、认证密码、加密密钥时启动失败；禁止使用默认值。

### P0-602 上传限制

限制 MIME、文件大小、像素数；不再通过 50MB JSON base64 作为唯一上传方式。

### P0-603 持久存储

Provider 配置和项目元数据不得依赖 Vercel `/tmp`。

### P0-604 数据删除

用户可删除项目和图片；明确默认保存周期。

## P1 功能

- P1-001 画笔蒙版和智能人物/对象选择；
- P1-002 生成两个候选并比较；
- P1-003 批量导入和队列；
- P1-004 复制/同步配方；
- P1-005 参考图角色：身份、色彩、风格、构图；
- P1-006 分享链接与批注；
- P1-007 AI 诊断建议；
- P1-008 Preview 客户模式。

## P2 功能

- 团队权限；
- 批量风格一致性；
- 自动质量评分；
- 模型基准和动态路由；
- RAW/色彩管理；
- 完整交付中心。

## 明确排除

- P0 不支持 PSD 图层；
- P0 不支持实时多人协作；
- P0 不支持全功能移动端编辑；
- P0 不以新增 Provider 数量作为成功标准；
- P0 不展示未经实测的转化率或效率数据。
