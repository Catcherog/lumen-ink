# Trae Prompt｜UI-001 V2 工作台外壳

前置条件：`SCAN-001` 已通过 GPT 审核，且实际组件路径已经映射。

## 目标

在不改变现有模型调用结果的前提下，建立 V2 工作台外壳：

- 顶栏：项目名、保存状态、撤销/重做、对比、导出、设置；
- 左栏：项目、人物、色彩、清理、局部、导出，必须有文字标签；
- 中央：画布与统一工具条；
- 右栏：上下文参数面板，360px；
- 底部：版本条占位；
- EMPTY 和 READY 两种状态；
- 使用 feature flag，旧版可回滚。

## 禁止

- 不改 Provider 实现；
- 不新增数据库；
- 不在本轮做异步任务；
- 不自行改变颜色 Token 或冻结文案；
- 不删除旧版代码，先保留回滚路径。
