# Trae Prompt｜UI-001 V2 工作台外壳

> 前置条件：`BASE-001` 已通过 GPT 验收。

## 1. 目标

建立可回滚的 V2 工作台外壳，不改变 Provider、API、Prompt 和生成结果：

- 增加 `VITE_EDITOR_V2`；
- Legacy 和 `AppV2` 并存；
- 顶栏展示项目上下文，不展示 Provider/模型；
- 左侧任务栏始终显示文字标签；
- 中央复用当前上传、画布、对比和下载能力；
- 右侧建立 360px 上下文面板容器；
- 底部建立版本区结构占位；
- 支持 EMPTY 和 READY；
- 1440×900、1280×800 可用。

## 2. 实现边界

建议新增：

- `src/client/src/AppV2.tsx`
- `src/client/src/components/v2/EditorHeader.tsx`
- `src/client/src/components/v2/TaskRail.tsx`
- `src/client/src/components/v2/ContextPanel.tsx`
- `src/client/src/components/v2/VersionStripPlaceholder.tsx`

允许复用 `ResultViewer`、`ImageUploader`、现有登录和 `useEditor`。

不得把 Legacy 代码复制一整套后再分叉维护。共享行为尽量复用，V2 只负责结构和呈现。

## 3. Feature flag

- `false`：完整 Legacy；
- 本地/Preview 可显式设为 `true`；
- Production 无变量时必须为 `false`；
- 不提交真实 `.env`；
- 提供切换和回滚说明。

## 4. 临时兼容规则

本轮不实现 EditRecipe，所以：

- 不新增第二个活跃“生成预览”按钮；
- 现有“应用/提交”可在 V2 兼容区域暂时保留；
- 必须在 UI 和交付报告中标记为 FLOW-001 临时债务；
- V2 Production flag 保持关闭。

不得为了“看起来完成”而用空按钮或假状态替代真实功能。

## 5. 顶栏规则

显示：

- 光砚标识；
- 项目名：未上传时“未命名项目”，上传后可用文件名；
- 临时状态：`当前会话`，不得写“已保存”；
- 对比、导出、设置入口；
- 退出登录。

不显示：

- Provider；
- 模型名称；
- API Key；
- 伪造的云保存状态。

## 6. 左栏

稳定文字标签：

- 项目
- 人物
- 色彩
- 清理
- 局部
- 导出

图标可保留，但文字不得依赖 hover 或展开态。

## 7. 底部版本占位

明确显示：

> 版本记录将在 VERSION-001 启用

不得把现有 history 直接改名为版本，也不得显示虚假的 V1/V2。

## 8. 验收

执行全部 baseline 命令并提供：

- Legacy 1440×900；
- V2 EMPTY 1440×900；
- V2 READY 1440×900；
- V2 READY 1280×800；
- feature flag 切换证据；
- 无横向溢出证据；
- 修改文件、已知临时债务和回滚方式。
