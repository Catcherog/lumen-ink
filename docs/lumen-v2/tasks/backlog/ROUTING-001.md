# Trae Prompt｜ROUTING-001 智能模型路由

> 前置条件：`JOB-001` 已通过。

## 目标

- 集中 Provider/模型能力矩阵；
- 实现质量、均衡、速度策略；
- 输出 fallbackChain；
- Provider 失败时按可解释规则转移；
- 高级抽屉允许查看或锁定模型；
- 记录路由原因、延迟和成本档位。

## 禁止

- 不在多个 Provider 文件中复制字符串判断；
- 不在失败时静默改变任务语义；
- 不暴露 API Key；
- 不把高级模型设置放回一级顶栏。

## 验收

- 能力矩阵单元测试；
- 三类策略路由测试；
- 故障转移测试；
- 不支持能力时给出明确 warning；
- 前端默认不显示 Provider/模型。
